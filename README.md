# Alembic website

The public website for Alembic (alembiclabs.com.au), by Alembic Labs.

- Static site, no build step yet. `index.html` is the placeholder holding page.
- Hosted on Cloudflare Pages, deploying from this repo's `main` branch.
- Domain registered at CrazyDomains, DNS on Cloudflare (free plan).
- The free MSE maker tool will live alongside the main site (Cloudflare Worker + KV for its shared vocabulary; design in the alembic repo at docs/launch/ and Alembic_Project_State.md).

House rules: no em or en dashes in copy; Australian English; marketing claims follow the claim ladder in the alembic repo's law wiki (docs/wiki/law/pages/marketing-law-claims.md).
