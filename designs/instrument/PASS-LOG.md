# The Instrument (instrument)
- Direction: Swiss-technical instrument manual on warm cream, every claim staged as a numbered figure, centrepiece is a living custody diagram where a hard boundary line is never crossed.
- Techniques: exposed 12/4 column hairline grid (fixed layer), CSS corner crop marks, self-drawing SVG via pathLength=100 plus stroke-dashoffset transitions driven by IntersectionObserver, marching-ants dashed flow lines inside the machine boundary, blocked-packet ping animation that dies at the boundary, dotted leader rows, instrument readouts with tick scales, Fraunces headlines against system mono callouts, gold reserved for the mark and one highlight per view.
- Build: v1 shipped all nine required blocks as Fig. 0 to Fig. 7 plus end plate and colophon; custody diagram is HTML content with tiny SVG stroke overlays so it stays legible from 375 px to 1440 px; complete reduced-motion variant renders every figure fully drawn.
- Pass 1: Tightened the phone Fig. 0 zone (apparatus viewBox cropped of its 104 units of dead top space, drawing widened to fill the column, caption and hero gaps pulled in, draw delays and duration compressed so the last stroke lands near 1.3s instead of 2.4s); reveal transition cut to 400ms with an 11px rise and a 35ms stagger capped at three; added a one-stroke drawn glyph to each of the six parts-list rows using the same pathLength trick.
- Pass 2: Added a full print stylesheet (white ground, black ink, gold reduced to outline, nav and buttons dropped, every figure forced fully drawn, break-inside protection on figures and plates, tool URLs printed after their labels, colophon last); gave every figure a stable id fig-0 to fig-7 with a self permalink on the figure label and a next sheet link on the sheet bar, rebuilt the phone INDEX as a list of figures, and pointed the desktop nav at the figure ids; reworked the custody ping into a single packet per chip that falls from the chip, flashes and dies at the X inside the first second, with the marching ants delayed 0.95s so the kill reads first; menu now closes on Escape (returning focus to the summary), on outside click and on link choice, and scrolls inside a 70vh cap.
- Pass 3: Final polish, four defects found and fixed: the closing call to action was printing the contact address in capitals (inherited mono uppercase), the Fig. 2 heading left "it." orphaned on its own line (non-breaking space plus text-wrap balance on all headings and pretty on body copy), every section closed with a row rule then a full top-sized pad before the next section rule so the bottom padding is now 0.75 of the top, and the page declared no colour scheme so a dark-mode UA painted its own chrome against the cream ground (color-scheme light).
